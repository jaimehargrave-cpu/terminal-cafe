# TerminalCafe

TerminalCafe is a terminal-first screensaver pack for macOS, Windows, and Linux. It turns a normal terminal into a developer-focused ambient display with animated, coding-inspired scenes.

Instead of a single static screen, TerminalCafe offers a collection of looping visual experiences: fake AI session output, code-rain motion, build monitor status, and a layered Creative Tools animation. Nothing in the scenes executes code or performs system actions; they are visual simulations designed for a hacker-terminal aesthetic.

## Features
- Terminal menu with keyboard navigation
- Multiple screensaver modes
- AI-style code typing animation
- Code-rain loop
- Build-monitor simulation
- Creative Tools animation with simultaneous orbiting objects, trails, and highlights
- No third-party packages required

## Screensaver modes
- AI Python Session
- Code Rain
- Build Monitor
- Creative Tools
- Exit

## Run

Python 3 is required.

```bash
python3 terminalcafe.py
```

Use:
- Up/Down or W/S to move through the menu
- Enter to launch a scene
- Ctrl+C to return to the menu
- q to quit from the menu
